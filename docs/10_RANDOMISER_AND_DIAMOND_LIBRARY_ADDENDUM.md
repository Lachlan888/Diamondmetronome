# Randomiser And Diamond Library Addendum

The diamond library and true randomiser are separate features.

## Diamond Library

The app should include a complete selectable list of number-pair diamonds up to 15.

Rules:

- Include ordered pairs from 1 to 15 where the two numbers are not equal.
- Include both orientations, such as `3/2` and `2/3`.
- Include reducible pairs, such as `2/4`, `3/6` and `4/8`.
- Do not automatically remove reducible pairs.
- The full list includes 210 ordered options when 1-based pairs are included.

Optional future filters:

- Show all
- Hide reducible pairs
- Show coprime only
- Hide 1-based pairs

These filters are optional and not required for the first pass.

## Library Behavior

- User can choose a diamond pair.
- User can load that diamond.
- User can load the inverse.
- Loaded diamonds remain editable.
- Loading a diamond applies live if playback is running.

Suggested module:

```text
src/lib/rhythm/diamondLibrary.ts
```

Suggested types:

```ts
export type DiamondPair = {
  id: string;
  numerator: number;
  denominator: number;
  name: string;
  inverseId: string;
};

export const diamondPairsUpToFifteen: DiamondPair[];

export function getDiamondPairById(id: string): DiamondPair | null;

export function getInverseDiamondPair(id: string): DiamondPair | null;
```

## Complete Ordered Pair Set

Generate the list programmatically from numbers 1 through 15:

```ts
const pairs = [];

for (let numerator = 1; numerator <= 15; numerator += 1) {
  for (let denominator = 1; denominator <= 15; denominator += 1) {
    if (numerator !== denominator) {
      pairs.push({ numerator, denominator });
    }
  }
}
```

This produces 210 ordered pairs.

## True Randomiser

The randomiser generates a new valid `DiamondPattern` randomly. It must not simply pick from the preset diamond library.

Do not implement randomiser behavior as:

```ts
const randomPreset = diamondPresets[Math.floor(Math.random() * diamondPresets.length)];
```

Minimum random generation rules:

- `numberA`: random integer from 1 to 15.
- `numberB`: random integer from 1 to 15.
- `numberA` and `numberB` cannot be equal.
- Cell values are generated from `numberA` and `numberB` according to the selected generation rule.
- Path is generated as a shuffled 9-cell path using each `CellId` exactly once.
- Repeated cells are not generated by the MVP randomiser.
- Non-adjacent cells are allowed.

Suggested label:

`Random Diamond: 7/4, full path`

Suggested module:

```text
src/lib/rhythm/randomDiamond.ts
```

Suggested type:

```ts
export type RandomDiamondOptions = {
  minValue: number;
  maxValue: number;
  includeOne: boolean;
  allowReduciblePairs: boolean;
};

export function generateRandomDiamond(
  options: RandomDiamondOptions
): DiamondPattern;
```

Default options:

```ts
{
  minValue: 1,
  maxValue: 15,
  includeOne: true,
  allowReduciblePairs: true,
}
```

## Acceptance Criteria

- Complete ordered pair list up to 15 is available.
- Both orientations are included.
- Reducible pairs remain available.
- Inverse lookup works.
- Loading a library pair applies live if playback is running.
- Random generation creates a new valid pattern from rules, not a selected preset.
- Random paths contain all 9 diamond cells exactly once.
- Random cell values remain valid.
