# Product Brief - Diamond Metronome

## Product Name

Diamond Metronome.

Previous working title: Rhythm Diamond Metronome.

## Summary

Diamond Metronome is an independent browser-based rhythm practice tool inspired by diamond-based rhythmic thinking and body-percussion pedagogy.

The app combines three synchronized layers:

- A grounded body-pulse sound, like a foot stomp.
- A constant subdivision sound, like a light finger click or hi-hat equivalent.
- An accent sound that moves through a visual diamond grid.

The user hears the underlying groove, hears the subdivision grid, and watches the accent travel through a diamond-shaped number pattern.

## Purpose

Provide a lightweight, local-first rhythm practice tool that helps musicians, students and teachers explore phrasing through a visual diamond, editable numeric cell values and custom movement paths.

## Primary Users

- Practicing musicians and percussion students
- Rhythm teachers and workshop facilitators
- Body-percussion learners
- Developers and designers iterating on rhythm-learning UI

## MVP Scope

- Fixed 9-cell diamond layout
- Editable cell values
- Default diamond pattern
- Custom path creation by clicking cells
- Start, stop and reset controls
- BPM and stomp interval controls
- Stomp, subdivision and accent sound layers
- Independent audio toggles for each sound layer
- Volume controls for each sound layer
- Active cell visual highlighting
- Current path display
- Local saving of at least one custom pattern
- Complete selectable diamond pair library up to 15
- True random diamond generation
- Simple, skinnable, natural hand-drawn UI direction

## Out Of Scope For MVP

- Supabase
- Database
- Auth
- Cloud saving
- API routes
- Server actions
- MIDI output
- VST or AU plugin
- DAW sync
- Notation export
- Sample upload
- Multi-user features
- Community sharing
- Mobile-native packaging
- Vercel configuration

## Positioning And Attribution Boundary

Use neutral wording:

Independent rhythm practice tool inspired by diamond-based rhythmic thinking and body-percussion pedagogy.

Diamond Metronome must not present itself as an official Greg Sheehan product, a complete recreation of Greg Sheehan's system, or a replacement for his teaching materials.
